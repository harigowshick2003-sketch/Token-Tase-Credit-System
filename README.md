\# Token Tase Credit System



This is the main repository for the Token-Based Tap-to-Pay \& Feedback System.



Folders:

\- backend/   → API \& Database

\- frontend/  → User UI

\- reader/    → NFC Reader (Raspberry Pi)

\- docs/      → Documentation

\- infra/     → Dev environment (Docker)

\- scripts/   → Utilities
